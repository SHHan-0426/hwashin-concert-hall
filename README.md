# 진화신의 공연장 — Hwashin Jin Concert Hall

소프라노이자 지휘자인 **진화신**의 디지털 공연장. 유튜브 이든채널(@이든티브이)과 연결된 별도 홈페이지입니다.

> **모바일 기반(mobile-first) 설계** — 휴대폰 화면을 기준으로 만들고 큰 화면은 확장합니다.
> 휴대폰에서는 화면 하단에 **탭바**(로비 · 무대 · 아티스트 · 이달의 무대 · 방명록)가 떠서
> 엄지로 누르는 앱처럼 이동합니다. 데스크탑(900px↑)에서는 탭바 대신 상단 메뉴가 나타납니다.
> 카드는 휴대폰 1열 → 태블릿 2열 → 데스크탑 3~4열로 자동 정렬됩니다.

## 구성

```
index.html              메인 페이지 (전체 공연장 — 한 페이지 구조)
assets/css/style.css    오페라하우스 테마 (딥 버건디·골드·아이보리)
assets/js/data.js       ★ 영상 카탈로그 — 운영자가 여기만 고치면 됩니다
assets/js/app.js        화면 그리기·모달 플레이어·방명록 로직
```

## 페이지 구성 (기획안 그대로)

- **로비(히어로)** — 붉은 벨벳 막 연출 + 통계 배너
- **오늘의 추천 프로그램** — `featured:true` 영상 자동 노출
- **네 개의 무대** — ① 독창 홀(아리아&가곡) ② 앙상블 홀 ③ 성가&찬송 홀 ④ 지휘 홀(마에스트라)
- **아티스트 룸** — 진화신 소개 + 함께한 아티스트 자동 집계
- **이달의 무대** — 월간 큐레이션
- **방명록 & 소통** — 감상 남기기·곡 신청·하트 반응·SNS 공유

## ★ 영상 연결하기 (가장 중요)

`assets/js/data.js`의 각 영상에서 `yt: ""` 자리에 **유튜브 영상 ID**를 넣으면 사이트 안에서 바로 재생됩니다.

```js
// 영상 주소가  https://youtu.be/abcd1234XYZ  이거나
//             https://www.youtube.com/watch?v=abcd1234XYZ  이면
{ hall:"solo", group:"한국 가곡", title:"동심초", sub:"김성태 곡", composer:"김성태", yt:"abcd1234XYZ" },
```

- `yt`를 채우면 → 썸네일 자동 표시 + 클릭 시 모달 플레이어로 인라인 재생
- `yt`가 비어 있어도("") → 클릭 시 유튜브 이든채널 검색으로 연결 (사이트는 정상 동작)

추천 노출은 `featured:true`, 이달의 무대는 `data.js` 맨 아래 `MONTHLY`에서 교체합니다.

## 배포 (Netlify / Vercel — 둘 다 무료)

빌드 과정이 없는 정적 사이트라 폴더째 올리면 끝입니다.

- **Netlify**: app.netlify.com → "Add new site" → 이 폴더 드래그&드롭, 또는 GitHub 저장소 연결
- **Vercel**: vercel.com → Import → Framework "Other" → 그대로 Deploy
- 도메인 예시: `hwashinjin.kr` / `soprano-hwashin.com`
